# Precisa de um início rápido?

Você tem duas opções para começar com um novo projeto Flight:

- [Full Skeleton Boilerplate](https://github.com/flightphp/skeleton): Um exemplo mais completo com controladores e visualizações.
- [Single File Skeleton Boilerplate](https://github.com/flightphp/skeleton-simple): Um único arquivo que inclui tudo o que você precisa para executar seu aplicativo em um único arquivo simples.

Exemplos contribuídos pela comunidade:

- [flightravel](https://github.com/fadrian06-templates/flighravel): FlightPHP com diretórios Laravel, com ferramentas PHP + GH Actions
- [fleact](https://github.com/flightphp/fleact) - Um kit inicial FlightPHP com integração ReactJS.
- [flastro](https://github.com/flightphp/flastro) - Um kit inicial FlightPHP com integração Astro.
- [velt](https://github.com/flightphp/velt) - Velt é um modelo inicial Svelte rápido e fácil com um backend FlightPHP.
- [vite-flightphp](https://github.com/pauloramoscuba/vite-flightphp) - FlightPHP e frontend moderno (Vite + Tailwind CSS) com recarga automática.
- [Flight Shield](https://github.com/enlivenapp/FlightPHP-Shield) - Autenticação.
- [Flight Settings](https://github.com/enlivenapp/FlightPHP-Settings) - Configurações baseadas em banco de dados.
- [Flight CSRF](https://github.com/enlivenapp/FlightPHP-CSRF) - Proteção CSRF.
- [Flight Sessions](https://github.com/enlivenapp/flight-sessions) - Sessões baseadas em banco de dados.
- [Flight School](https://github.com/enlivenapp/FlightPHP-Flight-School) - Gerenciador de plugins.
- [Flight Factory](https://github.com/enlivenapp/FlightPHP-Factory) - Comandos Runway para construir pacotes composer em vendor/ e componentes em app/.
- [Pubvana CMS](https://github.com/Pubvana-CMS/pubvana) - Um sistema de gerenciamento de conteúdo.

## Precisa de Alguma Inspiração?

Embora estes não sejam patrocinados oficialmente pela equipe do Flight, eles podem dar ideias sobre como estruturar seus próprios projetos construídos com Flight!

- [ASC REST API Spell Checker](https://github.com/AlMosahih-ASC/asc-api-sample) - Uma API REST leve para verificação ortográfica em árabe construída com FlightPHP e biblioteca ArPHP. Esta API fornece recursos de verificação ortográfica para texto em árabe, incluindo detecção de palavras com erros ortográficos e sugestões de correção.
- [Eventify](https://github.com/ilhanklisura/eventify) - Eventify é um aplicativo de página única que conecta organizadores de eventos com participantes. Construído com PHP (FlightPHP), JavaScript e MySQL, apresenta autenticação JWT, gerenciamento de eventos e documentação de API RESTful usando OpenAPI.
- [Ivox Car Rental](https://github.com/najtms/introductionToWeb) - Ivox Car Rental é um aplicativo web de aluguel de carros de página única e compatível com dispositivos móveis, construído com PHP (FlightPHP), JavaScript e MySQL. Ele suporta registro de usuários, navegação e reserva de carros, enquanto administradores podem gerenciar carros, usuários e reservas. O aplicativo possui uma API REST, autenticação JWT e um design responsivo para uma experiência moderna de aluguel.
- [Decay](https://github.com/boxybird/decay) - Flight v3 com HTMX e SleekDB, tudo sobre zumbis! ([Demonstração](https://decay.andrewrhyand.com))
- [Flight Example Blog](https://github.com/n0nag0n/flightphp-blog) - Flight v3 com Middleware, Controladores, Active Record e Latte.
- [Flight CRUD RESTful API](https://github.com/soheilkhaledabdi/php-crud-api-flight) - Projeto simples de API CRUD usando o framework Flight, que fornece uma estrutura básica para novos usuários configurarem rapidamente um aplicativo PHP com operações CRUD e conectividade com banco de dados. O projeto demonstra como usar Flight para desenvolvimento de API RESTful, tornando-o uma ferramenta de aprendizado ideal para iniciantes e um kit inicial útil para desenvolvedores mais experientes.
- [Flight School Management System](https://github.com/krmu/FlightPHP_School) - Flight v3
- [Paste Bin with Comments](https://github.com/n0nag0n/commie2) - Flight v3
- [Basic Skeleton App](https://github.com/markhughes/flight-skeleton)
- [Example Wiki](https://github.com/Skayo/FlightWiki)
- [The IT-Innovator PHP Framework Application](https://github.com/itinnovator/myphp-app)
- [LittleEducationalCMS (Espanhol)](https://github.com/casgin/LittleEducationalCMS)
- [Italian Yellow Pages API](https://github.com/chiccomagnus/PGAPI)
- [Generic Content Management System (with....very little documentation)](https://github.com/recepuncu/cms)
- [A tiny php framework based on Flight and medoo.](https://github.com/ycrao/tinyme)
- [Example MVC Application](https://github.com/paddypei/Flight-MVC)
- [Production ready Flight Boilerplate](https://github.com/madcoda9000/SecStore) - Framework de autenticação pronto para produção que economiza semanas de desenvolvimento. Possui segurança de nível empresarial: 2FA/TOTP, integração com LDAP, Azure SSO, limitação de taxa inteligente, impressão digital de sessão, proteção contra força bruta, painel de análises de segurança, registro de auditoria abrangente e controle de acesso baseado em funções granular.
