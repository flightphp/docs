# Butuh mulai cepat?

Anda punya dua opsi untuk memulai proyek Flight baru:

- [Full Skeleton Boilerplate](https://github.com/flightphp/skeleton): Contoh yang lebih lengkap dengan kontroler dan tampilan (views).
- [Single File Skeleton Boilerplate](https://github.com/flightphp/skeleton-simple): Satu file yang berisi semua yang Anda butuhkan untuk menjalankan aplikasi Anda dalam satu file sederhana.

Contoh kontribusi dari komunitas:

- [flightravel](https://github.com/fadrian06-templates/flighravel): FlightPHP dengan direktori ala Laravel, dengan perkakas PHP + GH Actions
- [fleact](https://github.com/flightphp/fleact) - Kit pemula FlightPHP dengan integrasi ReactJS.
- [flastro](https://github.com/flightphp/flastro) - Kit pemula FlightPHP dengan integrasi Astro.
- [velt](https://github.com/flightphp/velt) - Velt adalah template pemula Svelte yang cepat dan mudah dengan backend FlightPHP.
- [vite-flightphp](https://github.com/pauloramoscuba/vite-flightphp) - FlightPHP dan frontend modern (Vite + Tailwind CSS) dengan fitur muat ulang otomatis (hot reload).
- [Flight Shield](https://github.com/enlivenapp/FlightPHP-Shield) - Autentikasi.
- [Flight Settings](https://github.com/enlivenapp/FlightPHP-Settings) - Pengaturan berbasis basis data.
- [Flight CSRF](https://github.com/enlivenapp/FlightPHP-CSRF) - Perlindungan CSRF.
- [Flight Sessions](https://github.com/enlivenapp/flight-sessions) - Sesi berbasis basis data.
- [Flight School](https://github.com/enlivenapp/FlightPHP-Flight-School) - Manajer plugin.
- [Flight Factory](https://github.com/enlivenapp/FlightPHP-Factory) - Perintah Runway untuk membangun paket composer di vendor/ dan komponen di app/.
- [Pubvana CMS](https://github.com/Pubvana-CMS/pubvana) - Sistem manajemen konten.

## Butuh Inspirasi?

Meskipun ini tidak secara resmi disponsori oleh Tim Flight, ini bisa memberi Anda ide tentang cara menyusun proyek Anda sendiri yang dibangun dengan Flight!

- [ASC REST API Spell Checker](https://github.com/AlMosahih-ASC/asc-api-sample) - REST API ringan untuk pemeriksa ejaan bahasa Arab yang dibangun dengan FlightPHP dan pustaka ArPHP. API ini menyediakan kemampuan pemeriksaan ejaan teks bahasa Arab termasuk deteksi kata yang salah eja dan saran koreksi.
- [Eventify](https://github.com/ilhanklisura/eventify) - Eventify adalah aplikasi satu halaman (single-page app) yang menghubungkan penyelenggara acara dengan peserta. Dibangun dengan PHP (FlightPHP), JavaScript, dan MySQL, dilengkapi dengan autentikasi JWT, manajemen acara, dan dokumentasi API RESTful menggunakan OpenAPI.
- [Ivox Car Rental](https://github.com/najtms/introductionToWeb) - Ivox Car Rental adalah aplikasi web penyewaan mobil satu halaman yang ramah seluler, dibangun dengan PHP (FlightPHP), JavaScript, dan MySQL. Mendukung pendaftaran pengguna, penjelajahan, dan pemesanan mobil, sementara admin dapat mengelola mobil, pengguna, dan pemesanan. Aplikasi ini memiliki REST API, autentikasi JWT, dan desain responsif untuk pengalaman penyewaan modern.
- [Decay](https://github.com/boxybird/decay) - Flight v3 dengan HTMX dan SleekDB yang semuanya tentang zombie! ([Demo](https://decay.andrewrhyand.com))
- [Flight Example Blog](https://github.com/n0nag0n/flightphp-blog) - Flight v3 dengan Middleware, Kontroler, Active Record, dan Latte.
- [Flight CRUD RESTful API](https://github.com/soheilkhaledabdi/php-crud-api-flight) - Proyek API CRUD sederhana menggunakan kerangka kerja Flight, yang menyediakan struktur dasar bagi pengguna baru untuk dengan cepat menyiapkan aplikasi PHP dengan operasi CRUD dan konektivitas basis data. Proyek ini menunjukkan cara menggunakan Flight untuk pengembangan API RESTful, menjadikannya alat belajar yang ideal bagi pemula dan kit pemula yang berguna bagi pengembang yang lebih berpengalaman.
- [Flight School Management System](https://github.com/krmu/FlightPHP_School) - Flight v3
- [Paste Bin with Comments](https://github.com/n0nag0n/commie2) - Flight v3
- [Basic Skeleton App](https://github.com/markhughes/flight-skeleton)
- [Example Wiki](https://github.com/Skayo/FlightWiki)
- [The IT-Innovator PHP Framework Application](https://github.com/itinnovator/myphp-app)
- [LittleEducationalCMS (Spanyol)](https://github.com/casgin/LittleEducationalCMS)
- [Italian Yellow Pages API](https://github.com/chiccomagnus/PGAPI)
- [Sistem Manajemen Konten Umum (dengan....dokumentasi yang sangat sedikit)](https://github.com/recepuncu/cms)
- [Kerangka kerja PHP kecil berdasarkan Flight dan medoo.](https://github.com/ycrao/tinyme)
- [Contoh Aplikasi MVC](https://github.com/paddypei/Flight-MVC)
- [Flight Boilerplate Siap Produksi](https://github.com/madcoda9000/SecStore) - Kerangka kerja autentikasi siap produksi yang menghemat berminggu-minggu pengembangan. Dilengkapi keamanan tingkat perusahaan: 2FA/TOTP, integrasi LDAP, Azure SSO, pembatasan laju cerdas, sidik jari sesi, perlindungan brute-force, dasbor analitik keamanan, pencatatan audit yang komprehensif, dan kontrol akses berbasis peran yang granular.
