# 빠른 시작이 필요하신가요?

새 Flight 프로젝트를 시작하는 방법에는 두 가지 옵션이 있습니다:

- [전체 스켈레톤 기본 구조](https://github.com/flightphp/skeleton): 컨트롤러와 뷰를 포함한 보다 완전한 예제입니다.
- [단일 파일 스켈레톤 기본 구조](https://github.com/flightphp/skeleton-simple): 앱을 실행하는 데 필요한 모든 것을 포함하는 단일 파일입니다.

커뮤니티 기여 예제:

- [flightravel](https://github.com/fadrian06-templates/flighravel): Laravel 디렉터리 구조를 사용하는 FlightPHP와 PHP 도구 + GitHub Actions
- [fleact](https://github.com/flightphp/fleact) - ReactJS 통합을 포함한 FlightPHP 스타터 키트입니다.
- [flastro](https://github.com/flightphp/flastro) - Astro 통합을 포함한 FlightPHP 스타터 키트입니다.
- [velt](https://github.com/flightphp/velt) - Velt는 FlightPHP 백엔드를 사용하는 빠르고 쉬운 Svelte 스타터 템플릿입니다.
- [vite-flightphp](https://github.com/pauloramoscuba/vite-flightphp) - 핫 리로드를 지원하는 FlightPHP와 현대적인 프론트엔드(Vite + Tailwind CSS)입니다.
- [Flight Shield](https://github.com/enlivenapp/FlightPHP-Shield) - 인증.
- [Flight Settings](https://github.com/enlivenapp/FlightPHP-Settings) - 데이터베이스 기반 설정.
- [Flight CSRF](https://github.com/enlivenapp/FlightPHP-CSRF) - CSRF 보호.
- [Flight Sessions](https://github.com/enlivenapp/flight-sessions) - 데이터베이스 기반 세션.
- [Flight School](https://github.com/enlivenapp/FlightPHP-Flight-School) - 플러그인 관리자.
- [Flight Factory](https://github.com/enlivenapp/FlightPHP-Factory) - vendor/의 컴포저 패키지와 app/의 컴포넌트를 빌드하기 위한 Runway 명령입니다.
- [Pubvana CMS](https://github.com/Pubvana-CMS/pubvana) - 콘텐츠 관리 시스템.

## 영감이 필요하신가요?

이러한 예제들은 Flight 팀이 공식적으로 후원하지 않지만, Flight로 구축된 자신만의 프로젝트를 구성하는 방법에 대한 아이디어를 제공할 수 있습니다!

- [ASC REST API Spell Checker](https://github.com/AlMosahih-ASC/asc-api-sample) - FlightPHP 및 ArPHP 라이브러리로 구축된 아랍어 맞춤법 검사를 위한 경량 REST API입니다. 이 API는 철자가 틀린 단어 감지 및 수정 제안을 포함한 아랍어 텍스트 맞춤법 검사 기능을 제공합니다.
- [Eventify](https://github.com/ilhanklisura/eventify) - Eventify는 이벤트 주최자와 참석자를 연결하는 단일 페이지 앱입니다. PHP(FlightPHP), JavaScript 및 MySQL로 구축되었으며, JWT 인증, 이벤트 관리, OpenAPI를 사용하는 RESTful API 문서를 제공합니다.
- [Ivox Car Rental](https://github.com/najtms/introductionToWeb) - Ivox Car Rental은 PHP(FlightPHP), JavaScript 및 MySQL로 구축된 단일 페이지, 모바일 친화적인 자동차 렌탈 웹 애플리케이션입니다. 사용자 등록, 차량 탐색 및 예약을 지원하며, 관리자는 차량, 사용자 및 예약을 관리할 수 있습니다. 이 앱은 REST API, JWT 인증, 현대적인 렌탈 경험을 위한 반응형 디자인을 갖추고 있습니다.
- [Decay](https://github.com/boxybird/decay) - 좀비에 관한 모든 것을 다루는 HTMX 및 SleekDB를 사용한 Flight v3입니다! ([데모](https://decay.andrewrhyand.com))
- [Flight Example Blog](https://github.com/n0nag0n/flightphp-blog) - 미들웨어, 컨트롤러, Active Record 및 Latte를 사용하는 Flight v3입니다.
- [Flight CRUD RESTful API](https://github.com/soheilkhaledabdi/php-crud-api-flight) - Flight 프레임워크를 사용하는 간단한 CRUD API 프로젝트로, 새 사용자가 CRUD 작업 및 데이터베이스 연결을 통해 PHP 애플리케이션을 신속하게 설정할 수 있는 기본 구조를 제공합니다. 이 프로젝트는 RESTful API 개발에 Flight를 사용하는 방법을 보여주므로 초보자에게 이상적인 학습 도구이자 더 경험 많은 개발자에게 유용한 스타터 키트입니다.
- [Flight School Management System](https://github.com/krmu/FlightPHP_School) - Flight v3
- [Paste Bin with Comments](https://github.com/n0nag0n/commie2) - Flight v3
- [Basic Skeleton App](https://github.com/markhughes/flight-skeleton)
- [Example Wiki](https://github.com/Skayo/FlightWiki)
- [The IT-Innovator PHP Framework Application](https://github.com/itinnovator/myphp-app)
- [LittleEducationalCMS (Spanish)](https://github.com/casgin/LittleEducationalCMS)
- [Italian Yellow Pages API](https://github.com/chiccomagnus/PGAPI)
- [Generic Content Management System (with....very little documentation)](https://github.com/recepuncu/cms)
- [A tiny php framework based on Flight and medoo.](https://github.com/ycrao/tinyme)
- [Example MVC Application](https://github.com/paddypei/Flight-MVC)
- [Production ready Flight Boilerplate](https://github.com/madcoda9000/SecStore) - 개발 시간을 몇 주나 절약해 주는 프로덕션 준비 완료 인증 프레임워크입니다. 엔터프라이즈급 보안 기능을 제공합니다: 2FA/TOTP, LDAP 통합, Azure SSO, 지능형 속도 제한, 세션 지문, 무차별 대입 공격 방지, 보안 분석 대시보드, 포괄적인 감사 로깅, 세분화된 역할 기반 액세스 제어.
