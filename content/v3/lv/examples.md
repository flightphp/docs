# Vai nepieciešams ātrs sākums?

Jums ir divas iespējas, kā sākt darbu ar jaunu Flight projektu:

- [Pilns Skeleton Boilerplate](https://github.com/flightphp/skeleton): Pilnīgāks piemērs ar kontrolieriem un skatiem.
- [Viena faila Skeleton Boilerplate](https://github.com/flightphp/skeleton-simple): Viens fails, kurā ir viss nepieciešamais, lai palaistu savu lietotni vienā vienkāršā failā.

Kopienas veidotie piemēri:

- [flightravel](https://github.com/fadrian06-templates/flighravel): FlightPHP ar Laravel direktorijām, ar PHP rīkiem + GH Actions.
- [fleact](https://github.com/flightphp/fleact) - FlightPHP startera komplekts ar ReactJS integrāciju.
- [flastro](https://github.com/flightphp/flastro) - FlightPHP startera komplekts ar Astro integrāciju.
- [velt](https://github.com/flightphp/velt) - Velt ir ātra un vienkārša Svelte startera veidne ar FlightPHP back-endu.
- [vite-flightphp](https://github.com/pauloramoscuba/vite-flightphp) - FlightPHP un mūsdienīgs frontends (Vite + Tailwind CSS) ar karsto pārlādēšanu.
- [Flight Shield](https://github.com/enlivenapp/FlightPHP-Shield) - Autentifikācija.
- [Flight Settings](https://github.com/enlivenapp/FlightPHP-Settings) - Uz datubāzi balstīti iestatījumi.
- [Flight CSRF](https://github.com/enlivenapp/FlightPHP-CSRF) - CSRF aizsardzība.
- [Flight Sessions](https://github.com/enlivenapp/flight-sessions) - Uz datubāzi balstītas sesijas.
- [Flight School](https://github.com/enlivenapp/FlightPHP-Flight-School) - Papildinājumu pārvaldnieks.
- [Flight Factory](https://github.com/enlivenapp/FlightPHP-Factory) - Runway komandas, lai izveidotu Composer pakotnes mapē vendor/ un komponentus mapē app/.
- [Pubvana CMS](https://github.com/Pubvana-CMS/pubvana) - Satura pārvaldības sistēma.

## Vai nepieciešama iedvesma?

Lai gan šos oficiāli neatbalsta Flight komanda, tie var sniegt idejas, kā strukturēt savus projektus, kas veidoti ar Flight!

- [ASC REST API Spell Checker](https://github.com/AlMosahih-ASC/asc-api-sample) - Viegls REST API arābu pareizrakstības pārbaudei, veidots ar FlightPHP un ArPHP bibliotēku. Šis API nodrošina arābu teksta pareizrakstības pārbaudi, tostarp nepareizi uzrakstītu vārdu noteikšanu un labošanas ieteikumus.
- [Eventify](https://github.com/ilhanklisura/eventify) - Eventify ir vienas lapas lietotne, kas savieno pasākumu organizatorus ar apmeklētājiem. Veidota ar PHP (FlightPHP), JavaScript un MySQL, tā piedāvā JWT autentifikāciju, pasākumu pārvaldību un RESTful API dokumentāciju, izmantojot OpenAPI.
- [Ivox Car Rental](https://github.com/najtms/introductionToWeb) - Ivox Car Rental ir vienas lapas, mobilajām ierīcēm draudzīga automašīnu nomas tīmekļa lietotne, veidota ar PHP (FlightPHP), JavaScript un MySQL. Tā atbalsta lietotāju reģistrāciju, automašīnu pārlūkošanu un rezervēšanu, savukārt administratori var pārvaldīt automašīnas, lietotājus un rezervācijas. Lietotne ietver REST API, JWT autentifikāciju un responsīvu dizainu mūsdienīgai nomas pieredzei.
- [Decay](https://github.com/boxybird/decay) - Flight v3 ar HTMX un SleekDB, viss par zombijiem! ([Demo](https://decay.andrewrhyand.com))
- [Flight Example Blog](https://github.com/n0nag0n/flightphp-blog) - Flight v3 ar starpprogrammatūru, kontrolieriem, Active Record un Latte.
- [Flight CRUD RESTful API](https://github.com/soheilkhaledabdi/php-crud-api-flight) - Vienkāršs CRUD API projekts, kas izmanto Flight ietvaru un nodrošina pamatstruktūru, lai jaunie lietotāji ātri izveidotu PHP lietotni ar CRUD darbībām un datubāzes savienojumu. Projekts parāda, kā izmantot Flight RESTful API izstrādei, padarot to par ideālu mācību rīku iesācējiem un noderīgu startera komplektu pieredzējušākiem izstrādātājiem.
- [Flight School Management System](https://github.com/krmu/FlightPHP_School) - Flight v3
- [Paste Bin with Comments](https://github.com/n0nag0n/commie2) - Flight v3
- [Pamata Skeleton lietotne](https://github.com/markhughes/flight-skeleton)
- [Piemēra Wiki](https://github.com/Skayo/FlightWiki)
- [IT-Innovator PHP ietvara lietotne](https://github.com/itinnovator/myphp-app)
- [LittleEducationalCMS (spāņu)](https://github.com/casgin/LittleEducationalCMS)
- [Itāļu dzelteno lapu API](https://github.com/chiccomagnus/PGAPI)
- [Vispārēja satura pārvaldības sistēma (ar....ļoti maz dokumentācijas)](https://github.com/recepuncu/cms)
- [Mazs php ietvars, kas balstīts uz Flight un medoo.](https://github.com/ycrao/tinyme)
- [MVC lietotnes piemērs](https://github.com/paddypei/Flight-MVC)
- [Ražošanai gatavs Flight Boilerplate](https://github.com/madcoda9000/SecStore) - Ražošanai gatavs autentifikācijas ietvars, kas ietaupa vairāku nedēļu izstrādes laiku. Ietver uzņēmuma līmeņa drošību: 2FA/TOTP, LDAP integrāciju, Azure SSO, viedu pieprasījumu ierobežošanu, sesiju pirkstu nospiedumus, brute-force aizsardzību, drošības analīzes informācijas paneli, visaptverošu audita reģistrēšanu un detalizētu lomu piekļuves kontroli.

## Vai vēlaties dalīties ar savu piemēru?

Ja jums ir projekts, ar kuru vēlaties dalīties, lūdzu, iesniedziet pull request, lai to pievienotu šim sarakstam!
