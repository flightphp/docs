# Besoin d'un démarrage rapide ?

Vous avez deux options pour démarrer un nouveau projet Flight :

- [Full Skeleton Boilerplate](https://github.com/flightphp/skeleton) : un exemple plus complet avec des contrôleurs et des vues.
- [Single File Skeleton Boilerplate](https://github.com/flightphp/skeleton-simple) : un fichier unique qui contient tout ce dont vous avez besoin pour exécuter votre application dans un simple fichier.

Exemples contribués par la communauté :

- [flightravel](https://github.com/fadrian06-templates/flighravel) : FlightPHP avec des répertoires Laravel, avec des outils PHP + Actions GH
- [fleact](https://github.com/flightphp/fleact) - Un kit de démarrage FlightPHP avec intégration ReactJS.
- [flastro](https://github.com/flightphp/flastro) - Un kit de démarrage FlightPHP avec intégration Astro.
- [velt](https://github.com/flightphp/velt) - Velt est un modèle de démarrage Svelte rapide et facile avec un backend FlightPHP.
- [vite-flightphp](https://github.com/pauloramoscuba/vite-flightphp) - FlightPHP et frontend moderne (Vite + Tailwind CSS) avec rechargement à chaud.
- [Flight Shield](https://github.com/enlivenapp/FlightPHP-Shield) - Authentification.
- [Flight Settings](https://github.com/enlivenapp/FlightPHP-Settings) - Paramètres basés sur une base de données.
- [Flight CSRF](https://github.com/enlivenapp/FlightPHP-CSRF) - Protection CSRF.
- [Flight Sessions](https://github.com/enlivenapp/flight-sessions) - Sessions basées sur une base de données.
- [Flight School](https://github.com/enlivenapp/FlightPHP-Flight-School) - Gestionnaire de plugins.
- [Flight Factory](https://github.com/enlivenapp/FlightPHP-Factory) - Commandes Runway pour construire des paquets Composer dans vendor/ et des composants dans app/.
- [Pubvana CMS](https://github.com/Pubvana-CMS/pubvana) - Un système de gestion de contenu.

## Besoin d'inspiration ?

Bien que ceux-ci ne soient pas officiellement sponsorisés par l'équipe Flight, ils peuvent vous donner des idées sur la façon de structurer vos propres projets construits avec Flight !

- [ASC REST API Spell Checker](https://github.com/AlMosahih-ASC/asc-api-sample) - Une API REST légère pour la vérification orthographique de l'arabe construite avec FlightPHP et la bibliothèque ArPHP. Cette API fournit des capacités de vérification orthographique de texte arabe, y compris la détection de mots mal orthographiés et des suggestions de correction.
- [Eventify](https://github.com/ilhanklisura/eventify) - Eventify est une application monopage reliant les organisateurs d'événements aux participants. Construite avec PHP (FlightPHP), JavaScript et MySQL, elle propose une authentification JWT, la gestion d'événements et une documentation d'API RESTful utilisant OpenAPI.
- [Ivox Car Rental](https://github.com/najtms/introductionToWeb) - Ivox Car Rental est une application web de location de voitures monopage et adaptée aux mobiles, construite avec PHP (FlightPHP), JavaScript et MySQL. Elle prend en charge l'inscription des utilisateurs, la navigation et la réservation de voitures, tandis que les administrateurs peuvent gérer les voitures, les utilisateurs et les réservations. L'application propose une API REST, une authentification JWT et un design responsive pour une expérience de location moderne.
- [Decay](https://github.com/boxybird/decay) - Flight v3 avec HTMX et SleekDB, tout sur les zombies ! ([Démo](https://decay.andrewrhyand.com))
- [Flight Example Blog](https://github.com/n0nag0n/flightphp-blog) - Flight v3 avec Middleware, Contrôleurs, Active Record et Latte.
- [Flight CRUD RESTful API](https://github.com/soheilkhaledabdi/php-crud-api-flight) - Projet d'API CRUD simple utilisant le framework Flight, qui fournit une structure de base pour que les nouveaux utilisateurs puissent rapidement mettre en place une application PHP avec des opérations CRUD et une connexion à la base de données. Le projet montre comment utiliser Flight pour le développement d'API RESTful, ce qui en fait un outil d'apprentissage idéal pour les débutants et un kit de démarrage utile pour les développeurs plus expérimentés.
- [Flight School Management System](https://github.com/krmu/FlightPHP_School) - Flight v3
- [Paste Bin with Comments](https://github.com/n0nag0n/commie2) - Flight v3
- [Basic Skeleton App](https://github.com/markhughes/flight-skeleton)
- [Example Wiki](https://github.com/Skayo/FlightWiki)
- [The IT-Innovator PHP Framework Application](https://github.com/itinnovator/myphp-app)
- [LittleEducationalCMS (Spanish)](https://github.com/casgin/LittleEducationalCMS)
- [Italian Yellow Pages API](https://github.com/chiccomagnus/PGAPI)
- [Generic Content Management System (with....very little documentation)](https://github.com/recepuncu/cms)
- [A tiny php framework based on Flight and medoo.](https://github.com/ycrao/tinyme) - Un petit framework PHP basé sur Flight et medoo.
- [Example MVC Application](https://github.com/paddypei/Flight-MVC)
- [Production ready Flight Boilerplate](https://github.com/madcoda9000/SecStore) - Framework d'authentification prêt pour la production qui vous fait gagner des semaines de développement. Il comprend une sécurité de niveau entreprise : 2FA/TOTP, intégration LDAP, SSO Azure, limitation de débit intelligente, empreinte de session, protection contre la force brute, tableau de bord d'analyse de sécurité, journalisation d'audit complète et contrôle d'accès granulaire basé sur les rôles.
