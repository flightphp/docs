# 需要快速开始吗？

你有两种方式开始一个新的 Flight 项目：

- [完整骨架样板](https://github.com/flightphp/skeleton)：一个更完整的示例，包含控制器和视图。
- [单文件骨架样板](https://github.com/flightphp/skeleton-simple)：一个单文件，包含运行应用所需的一切，让你在单个简单文件中完成。

社区贡献示例：

- [flightravel](https://github.com/fadrian06-templates/flighravel)：FlightPHP 使用 Laravel 目录结构，带有 PHP 工具 + GH Actions
- [fleact](https://github.com/flightphp/fleact) - 一个带有 ReactJS 集成的 FlightPHP 入门套件。
- [flastro](https://github.com/flightphp/flastro) - 一个带有 Astro 集成的 FlightPHP 入门套件。
- [velt](https://github.com/flightphp/velt) - Velt 是一个快速简单的 Svelte 入门模板，后端使用 FlightPHP。
- [vite-flightphp](https://github.com/pauloramoscuba/vite-flightphp) - FlightPHP 与现代前端（Vite + Tailwind CSS），支持热重载。
- [Flight Shield](https://github.com/enlivenapp/FlightPHP-Shield) - 身份验证。
- [Flight Settings](https://github.com/enlivenapp/FlightPHP-Settings) - 基于数据库的设置。
- [Flight CSRF](https://github.com/enlivenapp/FlightPHP-CSRF) - CSRF 保护。
- [Flight Sessions](https://github.com/enlivenapp/flight-sessions) - 基于数据库的会话。
- [Flight School](https://github.com/enlivenapp/FlightPHP-Flight-School) - 插件管理器。
- [Flight Factory](https://github.com/enlivenapp/FlightPHP-Factory) - 用于在 vendor/ 中构建 composer 包、在 app/ 中构建组件的 Runway 命令。
- [Pubvana CMS](https://github.com/Pubvana-CMS/pubvana) - 一个内容管理系统。

## 需要一些灵感吗？

虽然这些并非由 Flight 团队官方赞助，但它们可以给你一些灵感，让你了解如何构建自己使用 Flight 的项目！

- [ASC REST API Spell Checker](https://github.com/AlMosahih-ASC/asc-api-sample) - 一个使用 FlightPHP 和 ArPHP 库构建的轻量级阿拉伯语拼写检查 REST API。此 API 提供阿拉伯语文本拼写检查功能，包括拼写错误单词检测和纠正建议。
- [Eventify](https://github.com/ilhanklisura/eventify) - Eventify 是一个单页应用，连接活动组织者和参与者。使用 PHP (FlightPHP)、JavaScript 和 MySQL 构建，具有 JWT 身份验证、活动管理，以及使用 OpenAPI 的 RESTful API 文档。
- [Ivox Car Rental](https://github.com/najtms/introductionToWeb) - Ivox Car Rental 是一个单页、移动友好的汽车租赁 Web 应用，使用 PHP (FlightPHP)、JavaScript 和 MySQL 构建。它支持用户注册、浏览和预订汽车，同时管理员可以管理汽车、用户和预订。该应用具有 REST API、JWT 身份验证和响应式设计，带来现代租赁体验。
- [Decay](https://github.com/boxybird/decay) - 使用 HTMX 和 SleekDB 的 Flight v3，全都关于僵尸！([演示](https://decay.andrewrhyand.com))
- [Flight Example Blog](https://github.com/n0nag0n/flightphp-blog) - 使用中间件、控制器、Active Record 和 Latte 的 Flight v3。
- [Flight CRUD RESTful API](https://github.com/soheilkhaledabdi/php-crud-api-flight) - 使用 Flight 框架的简单 CRUD API 项目，为新用户快速搭建带有 CRUD 操作和数据库连接的 PHP 应用提供了基础结构。该项目演示了如何使用 Flight 进行 RESTful API 开发，使其成为初学者的理想学习工具，也是更有经验的开发者的实用入门套件。
- [Flight School Management System](https://github.com/krmu/FlightPHP_School) - Flight v3
- [Paste Bin with Comments](https://github.com/n0nag0n/commie2) - Flight v3
- [Basic Skeleton App](https://github.com/markhughes/flight-skeleton)
- [Example Wiki](https://github.com/Skayo/FlightWiki)
- [The IT-Innovator PHP Framework Application](https://github.com/itinnovator/myphp-app)
- [LittleEducationalCMS (Spanish)](https://github.com/casgin/LittleEducationalCMS)
- [Italian Yellow Pages API](https://github.com/chiccomagnus/PGAPI)
- [Generic Content Management System (with....very little documentation)](https://github.com/recepuncu/cms)
- [A tiny php framework based on Flight and medoo.](https://github.com/ycrao/tinyme)
- [Example MVC Application](https://github.com/paddypei/Flight-MVC)
- [Production ready Flight Boilerplate](https://github.com/madcoda9000/SecStore) - 生产就绪的身份验证框架，可为你节省数周开发时间。具有企业级安全功能：2FA/TOTP、LDAP 集成、Azure SSO、智能限流、会话指纹识别、暴力破解保护、安全分析仪表板、全面的审计日志记录，以及细粒度的基于角色的访问控制。
