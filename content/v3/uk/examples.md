# Потрібен швидкий старт?

У вас є два варіанти, щоб розпочати новий проєкт на Flight:

- [Full Skeleton Boilerplate](https://github.com/flightphp/skeleton): Повноцінний приклад із контролерами та представленнями (views).
- [Single File Skeleton Boilerplate](https://github.com/flightphp/skeleton-simple): Один файл, який містить усе необхідне для запуску вашого застосунку в одному простому файлі.

Приклади від спільноти:

- [flightravel](https://github.com/fadrian06-templates/flighravel): FlightPHP зі структурою каталогів Laravel, інструментами PHP та GitHub Actions.
- [fleact](https://github.com/flightphp/fleact) — стартовий набір FlightPHP з інтеграцією ReactJS.
- [flastro](https://github.com/flightphp/flastro) — стартовий набір FlightPHP з інтеграцією Astro.
- [velt](https://github.com/flightphp/velt) — Velt — це швидкий і простий стартовий шаблон Svelte з бекендом на FlightPHP.
- [vite-flightphp](https://github.com/pauloramoscuba/vite-flightphp) — FlightPHP і сучасний фронтенд (Vite + Tailwind CSS) з гарячим перезавантаженням.
- [Flight Shield](https://github.com/enlivenapp/FlightPHP-Shield) — автентифікація.
- [Flight Settings](https://github.com/enlivenapp/FlightPHP-Settings) — налаштування на основі бази даних.
- [Flight CSRF](https://github.com/enlivenapp/FlightPHP-CSRF) — захист від CSRF.
- [Flight Sessions](https://github.com/enlivenapp/flight-sessions) — сесії на основі бази даних.
- [Flight School](https://github.com/enlivenapp/FlightPHP-Flight-School) — менеджер плагінів.
- [Flight Factory](https://github.com/enlivenapp/FlightPHP-Factory) — команди Runway для створення composer-пакетів у vendor/ та компонентів у app/.
- [Pubvana CMS](https://github.com/Pubvana-CMS/pubvana) — система керування вмістом.

## Потрібне натхнення?

Хоча вони не є офіційно спонсорованими командою Flight, вони можуть дати вам ідеї щодо структурування власних проєктів, створених на Flight!

- [ASC REST API Spell Checker](https://github.com/AlMosahih-ASC/asc-api-sample) — легковаговий REST API для перевірки арабської орфографії, створений на FlightPHP та бібліотеці ArPHP. Цей API надає можливості перевірки орфографії арабського тексту, включаючи виявлення помилок та пропозиції виправлень.
- [Eventify](https://github.com/ilhanklisura/eventify) — Eventify — це односторінковий застосунок, що поєднує організаторів подій із відвідувачами. Створений з використанням PHP (FlightPHP), JavaScript та MySQL, він має JWT-автентифікацію, управління подіями та документацію RESTful API на основі OpenAPI.
- [Ivox Car Rental](https://github.com/najtms/introductionToWeb) — Ivox Car Rental — це односторінковий, мобільно-дружній веб-застосунок для оренди автомобілів, створений на PHP (FlightPHP), JavaScript та MySQL. Він підтримує реєстрацію користувачів, перегляд і бронювання автомобілів, а адміністратори можуть керувати автомобілями, користувачами та бронюваннями. Застосунок має REST API, JWT-автентифікацію та адаптивний дизайн для сучасного досвіду оренди.
- [Decay](https://github.com/boxybird/decay) — Flight v3 з HTMX і SleekDB, усе про зомбі! ([Демо](https://decay.andrewrhyand.com))
- [Flight Example Blog](https://github.com/n0nag0n/flightphp-blog) — Flight v3 із Middleware, контролерами, Active Record та Latte.
- [Flight CRUD RESTful API](https://github.com/soheilkhaledabdi/php-crud-api-flight) — простий CRUD API-проєкт з використанням фреймворку Flight, який надає базову структуру для нових користувачів, щоб швидко налаштувати PHP-застосунок із CRUD-операціями та підключенням до бази даних. Проєкт демонструє, як використовувати Flight для розробки RESTful API, що робить його ідеальним навчальним інструментом для початківців і корисним стартовим набором для досвідченіших розробників.
- [Flight School Management System](https://github.com/krmu/FlightPHP_School) — Flight v3
- [Paste Bin with Comments](https://github.com/n0nag0n/commie2) — Flight v3
- [Базовий каркасний застосунок](https://github.com/markhughes/flight-skeleton)
- [Приклад вікі](https://github.com/Skayo/FlightWiki)
- [Застосунок на PHP-фреймворку від IT-Innovator](https://github.com/itinnovator/myphp-app)
- [LittleEducationalCMS (іспанською)](https://github.com/casgin/LittleEducationalCMS)
- [API італійських жовтих сторінок](https://github.com/chiccomagnus/PGAPI)
- [Загальна система керування вмістом (з....дуже малою документацією)](https://github.com/recepuncu/cms)
- [Крихітний PHP-фреймворк на основі Flight і medoo.](https://github.com/ycrao/tinyme)
- [Приклад MVC-застосунку](https://github.com/paddypei/Flight-MVC)
- [Готовий до продакшену Flight Boilerplate](https://github.com/madcoda9000/SecStore) — готова до продакшену система автентифікації, яка заощадить вам тижні розробки. Включає безпеку корпоративного рівня: 2FA/TOTP, інтеграцію LDAP, Azure SSO, інтелектуальне обмеження швидкості, зняття відбитків сесій, захист від brute-force, аналітичну панель безпеки, комплексне журналювання аудиту та детальне керування доступом на основі ролей.
